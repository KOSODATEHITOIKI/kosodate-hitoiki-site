ひと息

プライバシーポリシー

CenterRiverStudio（個人事業。以下「運営」）は、「ひと息」（以下「このサービス」）で取り扱う個人情報を、次のとおり、大切に扱います。

第1条（取得する情報）

運営は、次の情報を取得します。

区分 情報 取得の方法
アカウント メールアドレス（ログインのID）、パスワード（運営は読めない形で保存されます）。Googleでログインする場合は、Googleから渡されるメールアドレス・識別子 登録のとき、利用者の入力
プロフィール ニックネーム、アイコン（アプリのイラストまたはアップロードした画像）、自己紹介、子どもの年齢帯 利用者の入力
投稿など 投稿、コメント、返信、共感、保存、ブロック、ミュート、非表示 利用者の操作
通知 端末の通知用の識別子（トークン）、通知の設定 利用者の操作（通知の許可）
運営の記録 通報の内容、運営の対応の記録、利用規約への同意の記録（版と日時）、登録直後の制限などの管理に必要な記録 通報・運営の操作、登録
技術的な情報 動作の記録（ログ）。本文・パスワード・トークンは、記録に出さない方針です サービスの動作

自己紹介や投稿に、病気・障害・心の不調など、健康に関する情報を、利用者自身の意思で書くことがあります（個人情報保護法でいう「要配慮個人情報」に当たり得ます）。運営は、利用者が書いた範囲で、このサービスの運営に必要な目的にだけ、取り扱います。書く内容は、必要な範囲にとどめてください。

第2条（利用目的）

運営は、取得した情報を、次の目的に使います。これ以外の目的には、使いません。

  1. ログイン・本人確認、アカウントの管理
  2. 投稿・コメントなどの表示、検索、共感・保存などのサービスの提供
  3. 通知（アプリ内、プッシュ）の送信
  4. 荒らし・不正の防止（投稿前の自動チェック、通報の受付、一時非表示、削除・警告・利用停止、登録直後の制限）
  5. 不具合の調査、安全の確保、サービスの改善
  6. お問い合わせ、情報の開示・訂正・削除などのご依頼への対応
  7. 法令に基づく対応

第3条（他の利用者に見える情報）

  • 見える：ニックネーム、アイコン、投稿、コメント、返信。
  • 見えない（初期版）：メールアドレス、自己紹介、子どもの年齢帯。
  • 通報したことは、通報された人には、伝えません。

第4条（第三者への提供）

運営は、次の場合を除き、利用者の個人情報を、本人の同意なく、第三者に提供しません。

  1. 法令に基づく場合（裁判所・捜査機関などからの、法律に基づく求め）
  2. 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが困難な場合
  3. 次の第5条の、サービスの運営を委託する外部のサービスへ、必要な範囲で渡す場合

第5条（外部のサービスへの委託）

運営は、このサービスの運営のために、次の外部のサービスを使い、必要な範囲で、情報を渡します。

サービス 渡す情報 目的
Supabase（データベース・認証・サーバー処理） 取得するすべての情報 データの保管、ログイン、処理の実行
OpenAI（投稿前の自動チェック） 投稿・コメント・自己紹介・ニックネームの本文、アップロードした画像（保存の前）。メールアドレスなどの本人を特定する情報は、送りません 第5条（利用規約）に反していないかの、自動の確認
Resend（メール送信） メールアドレス、メールの本文（確認・パスワード再設定のリンク） ログインの確認、パスワード再設定のメール
Firebase Cloud Messaging（Google。プッシュ通知） 端末の通知用の識別子、通知の定型の文（投稿・コメントの内容は含めません） プッシュ通知の配信
GitHub（バックアップの保管） 暗号化したバックアップ（運営の秘密鍵がないと読めません）、削除の記録（IDと時刻だけを、暗号化したもの） 障害からの復旧のための、バックアップの保管
Cloudflare（ドメイン・配信） 運営者向けの管理画面の通信 運営者向けの管理画面の配信と、入口の保護
  • 渡す相手は、運営が、個人情報の保護のための契約・規約のもとで使うサービスです。運営は、必要な範囲を超えて渡しません。
  • 所在国・保存期間・取り扱い（2026-10-28に、各社の公式のページで確認した内容。変更されることがあるため、公開前に、もう一度確認する）：
サービス 所在国（サーバー・会社） 保存期間・学習などへの使用
Supabase データベース・認証・画像は、日本（東京。AWSのap-northeast-1）。運営会社はシンガポールと米国で、サポート・運用の一部は、国外から行われる。動作の記録（ログ）・利用情報は、選んだ地域の外で処理されることがある。国外への移転は、標準契約条項（SCC）による バックアップは、保持期間がプランによって異なる（運営の設定は、30日）
OpenAI 米国。国外への移転がある 学習には使われません（2023年3月以降のAPI。公式）。**投稿の確認に使う「モデレーションAPI」は、公式の表で、不正利用の監視のための保存も、アプリの状態の保存も「なし」**とされている。ただし、法律で必要な場合などは、例外がある
Resend 米国（主な処理は米国）。国外への移転は、標準契約条項（SCC）・データプライバシーフレームワーク（DPF）による アカウントの終了から90日以内に、データを削除する。メールのログ・本文を、個別に何日保存するかは、公式の資料で確認できていない
Firebase Cloud Messaging（Google） 世界各地のGoogleの拠点（地域は選べない）。国外への移転は、データプライバシーフレームワーク（DPF）による 端末の識別子は、削除の依頼（API）を呼ぶまで保存。削除のあと、180日以内に、バックアップを含めて削除される
GitHub 米国（中身は暗号化されており、GitHubは読めません） 31日で、自動で削除されます

外国にあるサービスに渡す場合の説明：上の表のとおり、OpenAI・Resend・GitHub・Googleは、米国などの外国にあります。運営は、各社が公開している規約・データ処理契約（標準契約条項、データプライバシーフレームワークへの参加など）を確認し、渡す情報を必要な範囲に限っています。投稿の自動チェックに送る本文・画像には、利用者を特定する情報（メールアドレスなど）を、含めません。バックアップは、運営だけが持つ鍵で暗号化してから、保管します。

第6条（保存の期間と、削除）

  • 利用者が退会すると、プロフィール、投稿、コメント、共感、保存、通知の設定、端末情報、ログインのアカウント、アップロードした画像などを、すぐに削除します。取り消せません。
  • 次のものは、一定期間、残ります。
残るもの 期間 理由
ニックネームの予約 30日 なりすまし・混乱の防止
運営の対応の記録（誰に、どの対応をしたか、理由） 1年 再発の判断、説明のため
通報の記録 1年 対応の確認、説明のため
バックアップ 30日 障害からの復旧のため（退会したデータが再び現れないよう、復元のときに削除し直します）
提供元のログ 各社の保持期間（本文・パスワード・トークンは記録しません） 安全の確保、不具合の調査
OpenAIに送った文章・画像 保存されません（投稿の確認に使うAPIは、公式の表で、不正利用の監視のための保存・アプリの状態の保存が「なし」。学習にも使われません）。ただし、法律で必要な場合などの例外は、OpenAIの規約による 自動チェックの実行
Firebase（Google）に渡した端末の識別子 退会で、運営が削除の依頼を出す。Googleでは、削除のあと180日以内に、バックアップを含めて削除される プッシュ通知の配信
  • 期限を過ぎた記録は、毎日、自動で削除します。

第7条（安全管理のための措置）

運営は、個人情報の漏えい・滅失・毀損を防ぐために、次の措置をとります。

  1. 通信の暗号化
  2. データへのアクセスの制限（利用者は、自分に関するデータと、公開されたデータだけに触れられる設計。投稿などの書き込みは、運営のサーバー処理を通す）
  3. 運営者の二段階認証、運営者向けの管理画面の入口の保護
  4. 鍵・パスワードの、コードへ含めない管理
  5. 動作の監視、攻撃の兆候の検知
  6. バックアップは、運営だけが持つ鍵で暗号化してから、保管します（保管の期間は、31日）。

万一、漏えいなどが起きたときは、法令に従って、個人情報保護委員会への報告と、本人へのお知らせを行います。

第8条（外部への送信について）

このサービスの端末のアプリは、解析・クラッシュ収集・広告のためのツールは、入れていません（2026年10月28日の時点）。端末の通知用の識別子は、通知の配信のために、Firebase Cloud Messaging（Google）へ送ります。

第9条（開示・訂正・利用停止・削除などのご依頼）

利用者は、運営が保有する、自分に関する情報について、開示、訂正、利用停止、削除を求めることができます。

  • 退会（削除）は、アプリの設定から、いつでも行えます。
  • 開示・訂正などのご依頼は、次の窓口へ、メールでお願いします。ご登録のメールアドレスからお送りください。確認のため、ご登録のメールアドレス宛てに、確認のご連絡をすることがあります。ご本人であることを確認できるまで、情報はお渡しできません。確認ができたら、遅れずに（目安は14日以内）対応します。
  • お渡しする情報は、プロフィール、投稿・コメント、各種の設定、同意した規約の記録、自分への運営の対応などです。通報した方が誰か、他の方の情報、運営の内部の管理情報は、お渡しできません。お渡しできないものがある場合は、その旨と理由をお伝えします。
  • 内容は、ご登録のメールアドレス宛てに、ファイルでお送りします。
  • 窓口：contact@kosodate-hitoiki.com
  • 手数料：かかりません

第10条（子どもについて）

このサービスは、18歳以上の方が対象です（利用規約案の第3条）。18歳未満の方の情報を、知らずに取得していたことが分かった場合は、すみやかに削除します。お子さまの情報（名前・顔・住所など）を、投稿に書かないでください。

第11条（このポリシーの変更）

運営は、必要があるときは、このポリシーを変更します。変更するときは、アプリ内で、内容と開始日を、事前にお知らせします。
