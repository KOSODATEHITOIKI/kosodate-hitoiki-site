利用規約

この規約は、「ひと息」（以下「このサービス」）を、運営者CenterRiverStudio（以下「運営」）が提供するにあたり、利用する方（以下「利用者」）と運営との間の約束ごとを定めるものです。利用者は、登録のときに、この規約に同意したものとします。

第1条（このサービスについて）

このサービスは、子育て中の方が、ぐち・相談・コツや体験談を、無理のない形で分かち合うための場です。医療・法律・育児の専門的な助言を提供するものではありません。体や心のことで不安があるときは、アプリ内の「困ったときの相談先」や、医療機関・公的な窓口をご利用ください。命や安全に関わる緊急のときは、110番・119番などへ連絡してください。

第2条（規約の変更）

運営は、必要があるときは、この規約を変更できます。変更するときは、アプリ内で、変更の内容と開始日を、事前にお知らせします。大きな変更のときは、あらためて同意をお願いすることがあります。変更の開始日以降に利用を続けた場合は、変更に同意したものとみなします。

第3条（利用できる方）

18歳以上の方が、利用できます。登録のときに、この条件を満たしていることを、利用者自身が確認します。18歳未満であることが分かった場合は、運営は、利用をお断りし、アカウントを削除することがあります。

第4条（アカウント）

  1. 利用者は、登録のときに、正しい情報を入力してください。
  2. メールアドレス・パスワードなどは、利用者自身の責任で管理してください。他の人に使わせたり、貸したりしないでください。
  3. アカウントの不正な利用に気づいたときは、すぐに、第15条の連絡先へお知らせください。
  4. 利用者は、いつでも、アプリの設定から、退会（アカウントの削除）ができます。退会すると、投稿などは、すぐに削除されます。取り消すことはできません。一部のデータが一定期間残ることは、プライバシーポリシーに書いています。

第5条（投稿のルール）

このサービスは、安心して書ける場所であることを、いちばん大切にします。次のことは、しないでください。

  1. 他の人を傷つける内容（誹謗中傷、攻撃、からかい、差別）
  2. 自分・家族・他の人が特定できる情報（本名、住所、電話番号、勤務先・園・学校の名前、顔や名前が分かる写真など）
  3. 勧誘・宣伝・営業・出会いを目的とする内容
  4. 他の人の文章・画像の無断の転載など、他の人の権利を侵害する内容
  5. 危険な行為をあおる内容、自分や他の人を傷つけることをすすめる内容
  6. 法令に反する内容、公序良俗に反する内容
  7. 不正アクセス、このサービスの動作を妨げる行為、複数のアカウントで規則を逃れる行為
  8. その他、運営が、このサービスの目的にふさわしくないと判断した内容

体や心の状態（病気・障害・心の不調など）を書くときは、必要な範囲にとどめてください。書いた内容は、他の利用者に表示されます。

第6条（投稿の権利と、運営が使える範囲）

  1. 投稿の権利は、投稿した利用者に残ります。
  2. 利用者は、運営に対し、投稿を、このサービスの運営に必要な範囲（保存、表示、通知、荒らしの防止、不具合の調査など）で、無償で使うことを許可します。広告や、このサービスの外での利用には、使いません。
  3. 他の人の権利を侵害しない内容だけを、投稿してください。

第7条（投稿前の自動チェック）

  1. 運営は、投稿・コメント・自己紹介・ニックネーム・画像が、第5条に反していないかを、自動で確認します。確認のために、外部のサービス（OpenAIの確認用のAPI）へ、本文や画像を送ります。送る範囲と扱いは、プライバシーポリシーに書いています。
  2. 自動の確認は、完全ではありません。問題ない内容が止まることや、問題のある内容が通ることがあります。止まったときは、表示された案内に従って、書き直してください。
  3. 確認の結果によっては、投稿を、保存せずに、お断りします。

第8条（通報と、運営の対応）

  1. 第5条に反する投稿を見つけたときは、通報できます。通報したことは、投稿した人には知らせません。
  2. 異なる3人から通報された投稿・コメントは、運営が確認するまでのあいだ、自動で一時的に非表示になります。誤って隠れた場合は、運営が確認して、元に戻します。
  3. 運営は、第5条に反する、またはそのおそれがある場合に、次の対応をとることがあります。
    • 投稿・コメントの削除（削除するときは、本人に、理由をお知らせします）
    • 警告
    • 一定の期間の利用停止（目安：初回は7日、再び反した場合は30日、その後は無期限。内容によっては、いきなり重い対応をとることがあります）
    • 相談先のご案内（心配な内容のとき）
  4. 運営は、対応の記録を、一定期間、保存します（保存期間は、プライバシーポリシー）。
  5. 対応に納得できないときは、第15条の連絡先へ、ご連絡ください。運営が、確認します。

第9条（サービスの変更・停止）

運営は、保守・障害・安全のため、事前の連絡なく、このサービスの全部または一部を、一時的に止めることがあります。このサービスの内容を、変更・終了することもあります。終了するときは、できるだけ早く、アプリ内でお知らせします。

第10条（保証しないこと）

  1. 運営は、このサービスが、いつでも、止まらず、誤りなく、安全に使えることを、保証しません。
  2. 他の利用者の投稿の内容が、正しいこと・安全なことを、保証しません。投稿の内容は、あくまで、他の利用者の経験や意見です。
  3. 運営は、アカウントの停止・削除、サービスの停止・終了によって、利用者に生じた損害について、運営に故意または重大な過失がある場合を除き、責任を負いません。
  4. 運営の責任が認められる場合でも、運営の賠償は、通常生じる損害の範囲に限ります。
  5. 消費者契約法など、法律の規定により、上の制限が認められない場合は、その範囲で、上の制限は、適用されません。

第11条（利用者の責任）

利用者が、この規約に反して、他の人または運営に損害を与えたときは、利用者が、その責任を負います。

第12条（個人情報の取り扱い）

利用者の個人情報は、別に定めるプライバシーポリシーに従って、取り扱います。

第13条（権利・義務の譲渡の禁止）

利用者は、運営の承諾なく、この規約に基づく権利・義務を、他の人に譲渡できません。

この規約は、日本の法律に従います。このサービスについて、争いが生じたときは、東京地方裁判所を、第一審の専属的な合意管轄の裁判所とします。
